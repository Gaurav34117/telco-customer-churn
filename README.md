# Telco Customer Churn Prediction

## Project Overview

Customer churn is one of the biggest challenges faced by telecom companies. Losing existing customers directly affects business growth and revenue. The main objective of this project is to build a machine learning model that can predict whether a customer is likely to leave the telecom service based on customer information, account details, and service usage.

The project follows a complete data science workflow starting from data collection and preprocessing to exploratory data analysis, model building, evaluation, and result visualization.

---

## Objectives

- Understand the customer churn problem.
- Explore the telecom customer dataset.
- Clean and preprocess the data.
- Perform exploratory data analysis.
- Train multiple machine learning models.
- Compare model performance.
- Predict customer churn accurately.
